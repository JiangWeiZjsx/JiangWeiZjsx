### Research Workflow (科研工作流)

- Paper Writing (论文写作)
    - PDF 路线：LaTeX 草稿 → PDF（或 `.tex`）→ 反馈 → 修订 → LaTeX 正式版。
    - Word 路线：Word 草稿 → PDF（或 `.docx`）→ 反馈 → 修订 → 转为 LaTeX 正式版。

- Presentation Report (演示报告)
    - 根据场景选择 PDF 或 PPT 版本。

- **Collaboration Suggestions (协作建议)**
    - Image (图片)：优先使用 `eps` 或 `png`。尺寸建议按 A4 页面控制，图中文字大小与正文保持一致。
    - Literature (文献)：使用可导出 `bib` 的工具（如 Zotero），便于统一管理。
    - Code (代码)：使用 `Docker` 管理环境，便于迁移、复现与开源。
    - Non-Formal Reports (非正式汇报)：组会、讨论等场景使用 PDF 展示即可。
    - Paper Submission (论文交付)：一般使用PDF 文件，同时保存 `tex` 源 (推荐) 或 `docx` 版本。
    - Formatting Requirements (格式要求)：无特殊要求时，采用正文（10pt）、标题（12pt）以及 1.25 倍行距，其余格式保证清晰、全文统一即可。
